# Contributing to djkaschkenya

Thank you for your interest in contributing to **djkaschkenya**! To get started, please follow these guidelines:

## Forking the Repository
1. Visit the djkaschkenya GitHub page: https://github.com/Haroldke13/djkaschkenya
2. Click the "Fork" button in the upper right corner to create your own copy of the repository.

## Creating a Branch
- After forking the repository, clone your fork to your local machine:
  ```bash
  git clone https://github.com/YOUR_USERNAME/djkaschkenya.git
  cd djkaschkenya
  ```
- Create a new branch for your feature or fix:
  ```bash
  git checkout -b feature-branch
  ```
  Replace `feature-branch` with a descriptive name for your new feature or fix.

## Commit Messages
- Use clear and descriptive commit messages. A good example is:
  ```
  Added user login feature
  ```
- Follow the format:
  - **Type:** (feat, fix, docs, style, refactor, perf, test, chore)
  - **Scope:** (optional)
  - **Description:**

## Code Style Guidelines
- Please adhere to the [PEP 8](https://peps.python.org/pep-0008/) style guide for Python code. Use tools like `flake8` or `pylint` to check your code style.

## Reporting Issues
1. Before reporting a new issue, please check if it exists already.
2. Provide detailed information about the issue, including steps to reproduce, expected behavior, and actual behavior.
3. Use descriptive titles for your issues, and categorize them if possible.

Thank you for your contributions!
